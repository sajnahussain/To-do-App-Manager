# 📝 To-Do App Manager

A simple and responsive To-Do App built with React.js to help users manage their daily tasks efficiently. The application allows users to add, edit, delete, and mark tasks as completed.

## ✨ Features

* **Add Tasks** — Create new tasks quickly using the input field.
* **View Tasks** — Display all added tasks in an organized list.
* **Edit Tasks** — Update existing task details.
* **Delete Tasks** — Remove tasks that are no longer needed.
* **Mark as Completed** — Mark tasks as completed using the checkbox.
* **Task Statistics** — View total, completed, and pending tasks.
* **Responsive Design** — Works across different screen sizes.

## 📖 How to Use

1. Enter a task in the "Add your Task..." input field.
2. Click the **+** button to add the task.
3. Use the checkbox to mark a task as completed.
4. Click the edit button to update a task.
5. Click the delete button to remove a task.
6. View the task summary at the bottom of the application.

## 📊 Task Management

The application displays three task statistics:

| Statistic   | Description                  |
| ----------- | ---------------------------- |
| Total Tasks | Total number of tasks added. |
| Completed   | Number of completed tasks.   |
| Pending     | Number of tasks remaining.   |
